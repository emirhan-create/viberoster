## 🌟 What is VibeRoster?

**VibeRoster** is an ultra-fast, open-source library of 120 curated, production-grade AI system instructions, `CLAUDE.md`, and `.cursorrules` files.

Designed for developers, designers, and everyday AI subscribers who want to skip prompt engineering guesswork, slash token consumption by up to 90%, and load battle-tested coding specialists into their daily workflows with a single click.

---

## 💰 Token & Context Savers (New!)

Tired of hitting Claude Pro message caps or burning expensive API context windows? VibeRoster includes 20 dedicated **Token & Cost Saver** specialists:
- **Claude Token Saver & Conciseness Protocol:** Eliminates conversational filler, polite intros, and full-file rewrites (cuts output tokens by 50-60%).
- **Repomix (Repopack) Codebase Packer (`16.5k ⭐`):** Consolidates entire codebases into token-efficient XML/Markdown payloads with token counting.
- **Gitingest Lean Repo Ingestion (`18.2k ⭐`):** Strips binaries and lockfiles to convert any GitHub repo into a minimal prompt.
- **Claude Prompt Caching Architect (`15.4k ⭐`):** Structures ephemeral cache breakpoints to trigger Anthropic's 90% prompt caching discount.
- **LLMLingua 20x Prompt Compressor (`8.6k ⭐`):** Microsoft's perplexity-based algorithm removing up to 80% of low-entropy tokens.
- **Aider Tree-Sitter Repo Map (`28.5k ⭐`):** PageRank-weighted symbol graph giving Claude full repository context in under 1,000 tokens.
- **Unified Diff Only Agent (`52.1k ⭐`):** Forces models to output standard unified diff patches instead of rewriting whole 500-line files.
- **ast-grep Context Trimmer (`11.2k ⭐`):** Injects only matching syntax tree nodes into Cursor Composer instead of entire folders.

## 🛡️ Zero PII & Security Shield

1. **Zero Personally Identifiable Information (Zero PII):**
   - No user accounts, passwords, emails, cookies, or remote server logs.
   - All preferences and active team rosters are stored strictly in client-side `localStorage`. No analytics trackers or telemetry scripts.
2. **Anti-Prompt-Injection Guardrails:**
   - Every agent embeds defensive protocols that strictly neutralize adversarial instructions (e.g. `"ignore previous instructions"`, jailbreaks, data exfiltration).
3. **Safe Clipboard Sanitization:**
   - All copied prompts and configurations are automatically cleansed of invisible control characters, bidirectional Unicode Trojan-source overrides (CVE-2021-42574), and dangerous scripts.

## 💻 Quick Start

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm or bun

### Run Locally
```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/viberoster.git
cd viberoster

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open your browser at:  
👉 **`http://localhost:5173`**

### Production Build
```bash
npm run build
npm run preview
```
